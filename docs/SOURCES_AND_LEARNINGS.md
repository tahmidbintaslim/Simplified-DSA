# Sources and Learnings

This file collects outside resources we can study while building Simplified DSA.

Use these sources for research, curriculum planning, examples, and inspiration. Do not copy code, book text, diagrams, or explanations into our project unless the license clearly allows it and we cite it.

## How To Use Sources

1. Read several sources before writing a lesson.
2. Extract the core idea in your own words.
3. Prefer official language docs for language syntax and runtime behavior.
4. Prefer university/open textbook sources for CS concepts.
5. Prefer high-quality repositories for topic order, example coverage, and practice prompts.
6. Add source links to each lesson under `## Sources Checked`.
7. Never copy-paste explanations. Our platform needs its own voice.

## Source Quality Tiers

### Tier 1: Fact Sources

Use these to verify correctness:

- Official language documentation
- Open textbooks
- University course material
- Standards/reference documentation

### Tier 2: Curriculum Sources

Use these to plan topic order and identify missing coverage:

- Popular DSA repositories
- Roadmaps
- Interview-prep lists
- Pattern collections

### Tier 3: Inspiration Sources

Use these for learning style, animation ideas, problem framing, and interaction ideas:

- YouTube explainers
- Interactive course platforms
- Visual tutorials
- Practice platforms

## What We Should Build From These Sources

### DSA Lesson Pattern

Each DSA lesson should include:

- Core idea
- Memory model
- Language comparison
- Runtime/compiler/interpreter notes
- Complexity
- Visual explanation plan
- Practice prompt
- Sources checked

### Problem-Solving Pattern

Each algorithmic pattern should include:

- When the pattern appears
- What signal tells the learner to use it
- One language-neutral pseudocode version
- Examples in the supported languages when useful
- Mistakes beginners make
- Practice prompts

### System Design Pattern

Future architecture lessons should include:

- User need
- Constraints
- Components
- Data flow
- Failure modes
- Scaling pressure
- Tradeoffs
- Diagrams or interactive simulations

## License and Attribution Rules

- Link every source used for lesson research.
- Do not copy code unless license and attribution requirements are clear.
- Do not copy diagrams. Redraw our own.
- Do not copy paid course content.
- Do not commit books or PDFs into this repository.
- Prefer short, original examples written for beginners.

## Review Checklist For New Sources

Before adding a source to a lesson, ask:

- Is it accurate?
- Is it maintained or still relevant?
- Is it official, academic, or widely trusted?
- What did we learn from it?
- Did we write the explanation ourselves?
- Did we add the link under `Sources Checked`?
