Privacy

Last updated: 9 November 2026

Short version: Simplified DSA does not collect, store, sell or share information about you. There are no accounts, no cookies, no analytics, no ads and no trackers.

The website

The lessons and demos run entirely in your browser. What you type into a demo stays on your device and disappears when you leave the page.

The site is hosted on Vercel. Like any web host, Vercel's servers see standard request data (such as your IP address, browser type and the page requested) to deliver the page and protect against abuse. We do not use that data. See Vercel's privacy policy.

Links to sources and documentation open other websites, which have their own privacy policies.

The Claude Code plugin and local MCP server

The plugin's server runs on your own computer. It reads the bundled lessons and computes algorithm traces locally. It sends nothing to us or anyone else.

The remote MCP connector

If you add the connector at https://dsa.tahmid.space/mcp to an AI assistant, the assistant sends tool requests to it, such as "trace merge sort on 5, 2, 9, 1". The connector computes the answer and returns it. It does not store requests, does not ask you to sign in, and does not identify you. Vercel's standard request logs apply, as above.

The assistant you use (for example Claude) has its own privacy policy, which covers your conversations.

Children

Simplified DSA is meant for learners aged 13 and older.

Changes and contact

If this ever changes, for example if we add analytics, this page will say so before the change goes live. The full history of this page is public in the project repository.

Questions: open an issue at github.com/tahmidbintaslim/Simplified-DSA/issues.
