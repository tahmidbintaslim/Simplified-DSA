# Simplified DSA Curriculum

This curriculum is split into two menus: **Data Structures** and **Algorithms**.

We write lessons slowly. Each lesson should explain the concept in our own words, use small JavaScript examples, and link the references checked during research.

## Data Structures

Data structures are ways to organize data so common operations become easier to reason about.

### Current Lessons

1. **Arrays and Strings**
   - Index-based access
   - Ordered values
   - Insert and delete shifting costs
   - String traversal

### Later Lessons

2. Linked Lists
3. Stacks and Queues
4. Hash Tables
5. Trees
6. Heaps
7. Graphs

## Algorithms

Algorithms are step-by-step procedures for solving problems.

### Current Lessons

1. **Big O**
   - Constant time
   - Linear time
   - Quadratic time
   - Why growth matters

### Later Lessons

2. Searching
3. Sorting
4. Recursion
5. Two Pointers
6. Sliding Window
7. Breadth-First Search
8. Depth-First Search

## Writing Rules

- Write for beginners without talking down to them.
- Prefer one clear example over many scattered examples.
- Use JavaScript for code snippets.
- Explain why an operation costs what it costs.
- Link sources, but do not copy their wording.
- Add visualizers only after the written explanation is clear.
