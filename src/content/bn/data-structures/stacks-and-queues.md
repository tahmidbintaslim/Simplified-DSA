# স্ট্যাক ও কিউ

স্ট্যাক আর কিউ মেমরিতে ডেটা রাখার নতুন কোনো উপায় নয়। এগুলো আসলে নিয়ম: এরপর কোন মানটা বের হবে। মাত্র দুটি ছোট্ট নিয়ম, অথচ এদের দেখা মেলে সবখানে: undo বাটন, প্রিন্টার, ওয়েব সার্ভার, এমনকি গোলকধাঁধা সমাধানেও।

> **উপমা:** স্ট্যাক হলো থালার একটা স্তূপ: তুমি ওপরে রাখো আর ওপর থেকেই নাও, তাই সবার শেষে রাখা থালাটাই সবার আগে বের হয়। কিউ হলো দোকানের লাইন: তুমি পেছনে দাঁড়াও আর সামনে থেকে বের হও, তাই যে আগে এসেছে সে-ই আগে যায়।

## স্ট্যাক: শেষে ঢুকলে আগে বের (LIFO) {#stack-last-in-first-out-lifo}

দুটি কাজ: `push` ওপরে যোগ করে, `pop` ওপর থেকে সরায়। আর `peek` ওপরের মানটা না সরিয়ে শুধু পড়ে।

```cells
values: 3 8 12
pointers: top=2
highlight: 2
note: push 3, push 8, push 12-এর পর। ওপরে আছে সবচেয়ে নতুন মান, 12।
```

```cells
values: 3 8
pointers: top=1
highlight: 1
note: pop-এর পর। 3 সবচেয়ে বেশিক্ষণ অপেক্ষা করলেও আগে বের হলো 12।
```

```quiz
Q: একটা খালি স্ট্যাকে প্রথমে A, তারপর B, তারপর C push করলে, এরপর একবার pop করলে। এখন ওপরে কী আছে?
- A
  Why not: A সবার আগে push হয়েছে, তাই সে আছে একদম নিচে। একবার pop করলে শুধু ওপরের জিনিসটা সরে।
* B
- C
  Why not: C সবার শেষে push হয়েছে, তাই pop ঠিক C-কেই সরায়। ভাবো, এর নিচে কী রয়ে গেল।
Why: C সবার শেষে push হয়েছে, তাই pop C-কে সরায়। ওপরে থাকে B।
```

## স্ট্যাক কোথায় কাজে লাগে {#where-stacks-show-up}

- **Undo:** প্রতিটি কাজ push করা হয়; undo সবচেয়ে সাম্প্রতিকটা pop করে।
- **ফাংশন কল:** কম্পিউটার প্রতিটি কল push করে, আর কল শেষ হলে pop করে। অসীম recursion হলে এটা ভরে যায়: সেটাই "stack overflow"।
- **ব্র্যাকেট মেলানো:** প্রতিটি `(` পেলে push, প্রতিটি `)` পেলে pop। শেষে স্ট্যাক খালি হলে ব্র্যাকেটগুলো মিলেছে।
- **Depth-first search:** যত গভীরে যাওয়া যায় যাও, তারপর পিছিয়ে আসো।

## কিউ: আগে ঢুকলে আগে বের (FIFO) {#queue-first-in-first-out-fifo}

দুটি কাজ: `enqueue` পেছনে যোগ হয়, `dequeue` সামনে থেকে বের হয়।

```cells
values: 3 8 12
pointers: front=0 back=2
highlight: 0
note: enqueue 3, enqueue 8, enqueue 12-এর পর। সামনে আছে সবচেয়ে পুরোনো মান, 3।
```

```cells
values: 8 12
pointers: front=0 back=1
highlight: 0
note: dequeue-এর পর। 3 আগে বের হলো, কারণ সে-ই সবচেয়ে বেশিক্ষণ অপেক্ষা করেছে।
```

একই মানগুলো push আর enqueue করো, তারপর দুটো থেকেই একটা করে সরাও। একই ইনপুট, আলাদা আউটপুট।

## এগুলো কীভাবে বানানো হয় {#how-they-are-built}

স্ট্যাকের জন্য dynamic array একদম মানানসই: push আর pop দুটোই হয় শেষ প্রান্তে, তাই কিছুই সরাতে হয় না।

> **সাবধান:** সাধারণ অ্যারের ওপর কিউ বানিয়ে ইনডেক্স 0 থেকে সরালে প্রতিটি মানকে বামে সরাতে হয়: প্রতিবার dequeue-তে `O(n)`। আসল কিউ বানানো হয় লিংকড লিস্ট বা ring buffer দিয়ে (এমন অ্যারে যার সামনের আর পেছনের ইনডেক্স ঘুরে আবার শুরুতে ফিরে আসে), তাতে dequeue থাকে `O(1)`।

> **কখন ব্যবহার করবে:** সবচেয়ে সাম্প্রতিক জিনিসটা যখন সবচেয়ে জরুরি (undo, nesting, backtracking), তখন স্ট্যাক। আসার ক্রম যখন জরুরি (কাজের তালিকা, মেসেজ, breadth-first search), তখন কিউ।

## খরচের হিসাব {#cost-cheat-sheet}

| কাজ | স্ট্যাক | কিউ |
| --- | --- | --- |
| যোগ করা | push `O(1)` | enqueue `O(1)` |
| সরানো | pop `O(1)` | dequeue `O(1)` |
| এরপর যেটা বের হবে সেটা দেখা | peek `O(1)` | peek `O(1)` |
| ভেতরে খোঁজা | `O(n)` | `O(n)` |

> **ইন্টারভিউ টিপ:** "Valid parentheses", "next greater element" আর "evaluate an expression" হলো স্ট্যাকের সমস্যা। "লেভেল ধরে প্রসেস করো" আর "কম ধাপে সবচেয়ে ছোট পথ" হলো কিউয়ের সমস্যা।

## মনে রাখো {#what-to-remember}

- স্ট্যাক উত্তর দেয়: "সবচেয়ে শেষে কী ঘটেছে?"
- কিউ উত্তর দেয়: "কে সবচেয়ে বেশিক্ষণ অপেক্ষা করছে?"
- breadth-first আর depth-first search-এর মধ্যে একমাত্র পার্থক্য হলো কিউয়ের জায়গায় স্ট্যাক বসানো।

## অনুশীলনী {#practice-prompt}

`( [ ] ( ) )` একটা স্ট্যাক দিয়ে যাচাই করো: প্রতিটি অক্ষরের পর স্ট্যাকটা কেমন দেখায় লেখো। তারপর `( ]` চেষ্টা করো, আর ঠিক কোন অক্ষরে গিয়ে আটকায় খুঁজে বের করো।

```answer
`( [ ] ( ) )`-এর ক্ষেত্রে প্রতিটি অক্ষরের পর স্ট্যাক:

1. `(` → `(`
2. `[` → `( [`
3. `]` ওপরের `[`-এর সাথে মেলে, pop → `(`
4. `(` → `( (`
5. `)` ওপরের `(`-এর সাথে মেলে, pop → `(`
6. `)` ওপরের `(`-এর সাথে মেলে, pop → খালি

শেষে স্ট্যাক খালি, তাই ব্র্যাকেটগুলো মিলেছে।

`( ]`-এর ক্ষেত্রে প্রথম অক্ষরের পর স্ট্যাকে থাকে `(`। দ্বিতীয় অক্ষর `]` ওপরের `(`-এর সাথে মেলে না, তাই যাচাই সেখানেই ব্যর্থ।
```
